# Frozen snapshot — do not treat as current

Everything in this directory is a **v0-era copy** of the Ambient source,
kept so the design system's original derivation can be traced. It is
severely out of date with the shipping app (React 19, 12 pattern types,
live wallpapers, no Flatpak, marketing site, Rust-owned settings, the
pattern manifest, …).

For current truth read the live code: `src/`, `src-tauri/`, and
`design-system/colors_and_type.css` (which the app itself imports).
